# ForeverLooter

A WoW: Forever fork of [MoneyLooter](https://github.com/will0w7/MoneyLooter) by Guillermo López Rodríguez (Will0w7), restyled with Blizzard UI elements so it feels natural in-game.

Install the `ForeverLooter` folder in `Interface/AddOns`. Use `/flo` or `/foreverlooter` to toggle the tracker.
